# Fake Store API v2.1.11 — API-тестирование в Postman

## О проекте

Практический проект по API-тестированию Fake Store API в Postman.

Проект содержит коллекцию из 21 тест-кейса для проверки CRUD-операций с ресурсом Products. Тесты включают позитивные и негативные сценарии, автоматические проверки ответов и параметризацию запросов с помощью переменных Postman.

## Покрываемые эндпоинты

- GET /products
- GET /products/{id}
- POST /products
- PUT /products/{id}
- DELETE /products/{id}

## Тестовое покрытие

### Позитивные сценарии

- Получение списка продуктов
- Получение продукта по существующему ID
- Создание продукта
- Обновление продукта
- Удаление продукта

### Негативные сценарии

- Несуществующий ID
- Некорректный ID
- Отсутствие обязательного поля
- Некорректный тип данных
- Пустое тело запроса
- Граничные значения
- Передача дополнительных полей
- Несоответствие ID

## Автоматические проверки

Для каждого запроса реализовано несколько автоматических проверок на JavaScript.

Проверяется:

- HTTP-статус ответа
- Тело ответа
- JSON Schema
- Время ответа
- Наличие обязательных полей
- Типы данных
- Бизнес-логика
- Корректность значений в ответе

## Возможности Postman

В проекте используются:

- Collection
- Переменные окружения
- Переменные запросов
- JavaScript-тесты
- Chai Assertions
- Collection Runner

Переменные используются для параметризации запросов и повторного использования тестовых данных.

## Тест-кейсы

Всего реализован 21 тест-кейс, включающий позитивные и негативные проверки CRUD-операций.

Тестирование направлено на проверку:

- корректного выполнения запросов;
- обработки невалидных данных;
- граничных значений;
- структуры и содержимого ответов;
- соответствия ответа ожидаемым условиям.

https://fakestoreapi.com

## Как запустить

1. Клонировать или скачать репозиторий.
2. Импортировать Postman-коллекцию.
3. При необходимости импортировать окружение.
4. Выбрать нужное окружение.
5. Запустить отдельные запросы или всю коллекцию через Collection Runner.

## Примечания

Fake Store API является публичным mock API и предназначен для тестирования.

Операции создания, обновления и удаления данных симулируются и не гарантируют постоянного изменения данных на сервере.

При повторных запусках коллекции некоторые ответы могут отличаться из-за особенностей публичного demo API.
